# 읽는 법
#  - 두 rps 가 정확히 같다(19.267) = 같은 iteration 에서 1:1 로 호출됐다는 확인.
#  - 응답 크기는 203 B 대 약 46 KB 로 2자리 차이인데 서버 비용은 사실상 같다.
#    오히려 집계가 평균 7% 비싸다(3.785 vs 3.538).
#  - 둘 다 performance_id 로 같은 행을 읽는다. 차이는 그 다음이다 —
#    집계는 행마다 CASE WHEN 4개와 hold_expired_at 비교를 하고 203 B 를 만들고,
#    좌석맵은 행을 그대로 DTO 로 옮겨 46 KB 를 만든다. 실측은 그 둘이 맞먹는다고 말한다.
#  - 따라서 "집계 API 는 가벼운 조회" 라는 전제는 이 규모에서 성립하지 않는다.
#    응답이 작다는 것이 서버가 싸다는 뜻이 아니다.
#
# ⚠ 스케일 B(3,000석)에서는 이 비교를 하지 않았다. 3,000석 좌석맵 응답이 CPU·메모리를 삼켜
