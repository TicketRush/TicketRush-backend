#   소화 시간   = C/m = 300s   (admit 과 무관하게 상수 → 계단마다 같은 5분 판정창)
#   VU_MODEL_PEAK = C x (1 - m/a) = C/2   (유입 종료 시점이 피크)
#   ⚠ SSE 구독자는 별도 시나리오라 이 예산 밖이다. 다만 k6 의 vus_max 는 전 시나리오 합이므로
#     dropped 판별에서는 구독자 수를 뺀다.
#
# ⚠ 도착률은 admit 보다 커야 한다. a <= m 이면 대기가 안 쌓이고 예매 RPS 가 도착률에서
#   평평해져 admit 이 아니라 부하 모델을 재게 된다 — #554 §10.1 이 "33.73 은 부하 모델이
#   만든 상한이지 시스템의 한계가 아니다" 라고 적은 그 상태다.
#
# 계단표 (런북 §16.7)
#   m     a     C        계획 iter   VU_MODEL_PEAK   maxVUs

#   20    40    6,000    5,800       3,000           4,000
#   30    60    9,000    8,700       4,500           5,400
