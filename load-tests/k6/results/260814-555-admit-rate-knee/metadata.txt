# ── 부하 모델 산술 (모든 판정의 전제 — 회차 전에 못 박는다) ────────────────
# 도착률 a = 2m, 코호트 C = 300m 으로 두면
#   유입 시간   = C/a = 150s   (admit 과 무관하게 상수 → HOLD 는 전 계단 140s 로 같다)
#   소화 시간   = C/m = 300s   (admit 과 무관하게 상수 → 계단마다 같은 5분 판정창)
#   VU_MODEL_PEAK = C x (1 - m/a) + m x 체류초 = C/2 + 10m   (유입 종료 시점이 피크)
#
# ⚠ 도착률은 admit 보다 커야 한다. a <= m 이면 대기가 안 쌓이고 예매 RPS 가 도착률에서
#   평평해져 admit 이 아니라 부하 모델을 재게 된다 — #554 §10.1 이 "33.73 은 부하 모델이
#   만든 상한이지 시스템의 한계가 아니다" 라고 적은 그 상태다.
#
# 계단표 (런북 §16.7)
#   m     a     C        계획 iter   VU_MODEL_PEAK   maxVUs
#   12    24    3,600    3,480       1,920           2,400
#   20    40    6,000    5,800       3,200           4,000
#   30    60    9,000    8,700       4,800           5,800
#   40    80   12,000   11,600       6,400           7,700
#   80   160   24,000   23,200      12,800          15,400
#  160   320   48,000   46,400      25,600          30,800
#
# ⚠ preAllocatedVUs = maxVUs 로 둔다. 다르면 k6 가 VU 를 지연 생성하고 그 지연 자체가
#   dropped_iterations 를 만들어, 이 회차에서 dropped 를 '대상 포화' 와 구분할 수 없다.

# ── 계단 수열 — 이분 탐색. 정지 규칙을 회차 전에 정한다 ────────────────────
