  알림 발화(04:47Z). 정상 디렉토리 ~/ticketrush/deploy/ 에서 `up -d redis mysql seat-service` 재실행으로
  04:58Z 복구(redis_up=1, 전 서비스 AUTH 오류 0, restarts=0). 볼륨이 명시적 이름이라 데이터 손실 없음.
  실제 배포 경로는 컨테이너 라벨 com.docker.compose.project.config_files 로 확인한다. 런북 §11.4에 고정.
